Ask for temporary access in plain English. Aegis turns the request into a policy, decides it, sends risky access for a second person's approval, revokes grants when they expire, and records every step in a tamper-evident audit trail.

This is the real Aegis API (FastAPI, SQLAlchemy and SQLite) running in your browser as Python compiled to WebAssembly. Everyone in it is fictional, nothing leaves this page, and it starts over when you reload. Requests are read by Aegis's offline keyword parser here; the server version uses Claude.
